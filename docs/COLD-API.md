# 冷处理 API 与纠正学习 · 0.1.3

Satori 的主体是本地习惯助手，可选 API 只在需要解释陌生情况时醒来。一次网络调用的价值应该留下可复用的本地经验。

## 已落地的循环

1. 本地处理熟悉的应用、词句和数值偏好。
2. 用户手动改变或撤销助手音量，立即停止当前场景自动改动。外接屏通过手动设置接口或15秒探测发现纠正，停止该场景自动改动。
3. 仅助手最近5分钟内、同会话的已执行调节被随后改变，或用户明确拒绝建议，计为纠正证据；普通初次手动设置只训练偏好。
4. 同一场景去重，两个独立场景形成局部例外；没有 API 也生效。
5. 可选层开启后，重复纠正的未知适用边界，或多次出现相近程序候选，产生有限待解释事件。新应用本身、每次按键、每次数值调整不会唤醒。
6. AI 提出限定类型解释。结果不自动扩大规则、不自动启动。用户确认后由本地复核，SQLite 保存边界或程序选择。
7. 熟悉例外和程序选择在本地复用。同事件成功、失败、拒绝均不循环请求。

这种“梦游”是本地规则运行、模型休眠，不是模型后台持续推理。

## 经验的边界

经验按软件、设备、6小时时段、activity 匹配。当前 activity 主要是桌面/软件前台状态，没有通话、会议或环境光检测。不能因为软件名猜测用户正在通话。例外默认30天有效，最多500条；用户可忘记。

新规则是保持手动设置，或优先建议明确选过的程序；不会授予更大系统执行权限。API 不可用时，本地仍可学习局部例外，程序六宫格仍可点击打开并学习明确选择。保持系统自己的输出不训练自己；没有撤销不作为满意证明。

## 独立调用层

cold_ai.rs 保存可选会话凭据，单独线程检查待解释事件。默认不开启。关闭清除凭据并通过配置世代号取消请求；暂停、关闭相关功能、切换会话、证据更新或清除经验会使结果失效。请求最多30秒，HTTP禁止重定向。

认领时在SQLite记录调用，自动最多5次/UTC日，间隔600秒；全部调用合计50次/UTC日。认领后崩溃视为 interrupted，不开机自动重试。不删除调用预算以获得额外请求。

AI 只接收有限名称、时段、次数及少量临时候选，响应采用严格枚举和字段验证；不执行生成代码。框架可扩展新的类型化能力，但本版不加入通用多步任务。

## 状态与可观察性

首页显示经验数量、本地复用计数、当日自动调用次数，AI层显示未连接/休眠/理解中。新AI候选以不抢焦点的浮卡提示，主面板进行确认。每条候选有版本，旧卡重复点击不能重复打开程序。

## 测试与限制

tests/cold_ai.rs 直接编译生产 cold_ai.rs，替换最末端传输，验证关API零请求、暂停/敏感场景不唤醒、单事件一次调用、确认前不扩大规则、断线本地规则仍在、预算与经验持久化。

tests/experience.rs 验证音量执行→撤销→独立纠正→本地例外，以及程序确认与离线选择。此验证不代表真实服务商、PowerShell取消、外接屏读写或原生UIA已真机验收。

现有快速词基于输入暂停候选而非通用“已发送”信号；原有词库/亮度偏好仍保存在JSON，新规则与预算在SQLite。外接屏读取仍为15秒轮询，未加入热插拔事件或DDC故障进程隔离。无扩展网址读取不在本版实现范围。
