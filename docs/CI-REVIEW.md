# v0.1.5：CI 风险与工程决策

审查对象是源码包自带的 GitHub Actions、测试及生产代码；没有远程仓库的运行记录，不能断言具体远程提交已通过。改动围绕已复现的问题与明确的测试缺口，保留现有 Rust/Tauri/Svelte/SQLite 责任划分。本地优先、可选 API、有限执行权、敏感场景护栏、SQLite schema 5 和数据库同步策略未改变。

## 从成熟项目文档提炼的原则

这些是设计参考，不是引入其代码或依赖。

1. [Qt QSaveFile](https://doc.qt.io/qt-6/qsavefile.html)：设置文件写入应有提交点，失败不能破坏原文件。本项目用现有 Rust/UUID 依赖实现同目录临时文件与失败清理；不开启直接覆盖旧文件的退路。文件同步与替换降低写入失败风险，不承诺任意断电、异常文件系统下零损失。
2. [VS Code API](https://code.visualstudio.com/api/references/vscode-api)：取消信号和 Disposable 明确异步任务及资源的有效期。本项目保留自己的序号与生命周期模型，并在迟到结果提交时再次核验；取消不等于对方一定停止处理。
3. [Playwright Clock](https://playwright.dev/docs/clock) 与 [Assertions](https://playwright.dev/docs/test-assertions)：时序行为用可控时钟推进，结果用可重试断言观察。本项目没有通过扩大超时、删除断言或开启重试来掩盖原故障。
4. [Rust fs::rename](https://doc.rust-lang.org/std/fs/fn.rename.html)：遵循平台替换语义，同目录暂存避免跨卷移动；遇到权限、占用或替换错误就保留旧内存并报告失败。
5. [GitHub runner-images](https://github.com/actions/runner-images)：用明确 OS 标签减小 latest 迁移影响。标签不等于冻结整张镜像，锁文件和编译器版本继续承担可重复构建责任。
6. [Microsoft WebView2 分发](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)：不能把安装 Edge 浏览器当成 WebView2 Runtime 已存在。CI 检查运行时注册信息，需要时安装微软签名的 Evergreen 引导程序，再启动演示包；普通用户的便携包不自动运行安装器。

## 有意保留的设计

没有为了“优化”降低 SQLite 持久化要求、减少敏感状态核验、放宽 API/执行权限、改变学习率或无证据地加长轮询。没有升级第三方依赖版本，也没有替换现有分层架构。新增 tempfile 为测试用途；辅助保存模块可脱离 Windows 运行故障回归。

## Issue 与 PR

已有 bug 模板、贡献说明和 Dependabot 保留；补充 PR 模板。报告时给出完整修订包的 EXE 哈希、真实/演示/网页模式、Windows 与 WebView2 版本、复现步骤及脱敏错误。异步竞争尽量提交可控顺序的回归；硬件问题给出显示器/接口或输入控件类型。不能把网页 mock 通过当成原生功能验收，也不上传真实数据库、密钥或私人路径。

本地已通过的项目、已编译而未执行的项目及真机范围以 BUILD-INFO.md 为准。后续 issue/PR 是维护入口，不替代发布前的 Windows 真机验收。
