# Satori v0.1.0 Alpha

首个公开版本，整理自内部 0.3.0 原型；公开编号重新从 0.1.0 开始，功能与 schema 5 保留。源代码按 MIT 发布，第三方组件采用各自许可。

## 包含什么

- 无需 API 的应用习惯推荐、音量/外接屏亮度微调、快速词和本地纠正学习。
- 可选冷处理 AI：反复陌生冲突/程序歧义才唤醒；经确认的经验存入 SQLite，后续本地复用。AI 没有执行权。
- 设置页新增独立的「开机自启动」大开关，默认关闭，登录 Windows 后后台运行，只使用当前用户 Run 启动项。关闭不受当前程序路径是否适合启用的影响。演示模式不写真实启动项。
- 经验查看与忘记、持久化调用预算、取消与过期响应检查。删除快速词后抑制重新学习，手动添加可恢复。
- 四页界面：首页、自动调节、快速词、设置；没有通用多步任务或任意桌面 Agent。

API 默认关闭，关闭、超时或预算耗尽不影响本地功能；密钥仅本次运行内存保存，退出后需重新连接。同个陌生事件不循环重试；扩大例外范围或打开程序须明确确认。

## 下载包与升级

`Satori-v0.1.0-source.zip`：完整公开源码、锁文件、测试、CI、文档与第三方许可；不含 exe、构建缓存或真实用户数据。解压后的文件直接放仓库根目录。

`Satori-v0.1.0-windows-x64.zip`：便携式运行包，含程序、启动脚本、WebView2Loader、可选浏览器扩展和许可。需 Windows x64 与 WebView2 Runtime；完整解压后运行 `Start-Background.cmd`。设置页可开启开机启动，建议先放固定路径。运行包没有签名安装器或自动更新。

数据标识仍为 `io.habitos.desktop`。升级前退出旧版并备份应用数据；schema 5 保留应用、音量和权限。旧程序不能打开升级后的数据库，想回退时须使用升级前备份。快速词及亮度原有偏好仍在 assist.json，新增例外与调用预算在 SQLite。

## 尚需真机验收

Windows 真实启动项、托盘和浮卡焦点；不同控件的 UIA/IME；真实外接屏 DDC/CI；真实 API 服务商及网络中止；资源占用。网页模拟、替代传输和交叉编译不能替代这些检查。网站观察目前仍需 Chrome/Edge 扩展，没有 DNS 监听或无扩展地址读取。
