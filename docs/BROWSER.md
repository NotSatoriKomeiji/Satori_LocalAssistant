# 浏览器快速词与网站观察

这是可选连接，当前支持 Windows x64 的 Chrome/Edge。没有无扩展网址读取；不想用浏览器功能可以不安装。Windows 浏览器桥接还需真机验收。

## 安装运行包中的扩展

1. 完整解压运行包，保持 `browser-extension` 与 `satori.exe` 在同一目录。先把程序放到固定位置。
2. 双击 `browser-extension/Install-Bridge.cmd`。脚本为当前用户登记 Chrome/Edge 的本机连接，并生成带本机路径的 `native-host.json`，无需管理员权限。
3. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，选择「加载已解压的扩展程序」，选择运行包里的 `browser-extension` 文件夹。固定 ID 应为 `bppdnglijnadiobjlmnkammkmgfeiapm`。
4. 启动真实 Satori，开启「快速词」。在普通 HTTPS 页面输入，点击右下角候选输入。扩展图标可查看连接状态，Enter/Backspace 和输入法按键仍由原输入框处理。
5. 网站学习另在 Satori「设置 → 网站与浏览器」开启，默认关闭；与快速词开关分开。

源码目录的扩展也可开发调试，但 `Install-Bridge.ps1` 预期上一级已有编译完成的 `satori.exe`。不要直接在纯源码目录运行安装脚本。

## 边界

快速词只处理普通、可编辑字段；密码、账户、支付、隐私窗口、后台页面等跳过。敏感过滤不能识别所有私人文字，遇到不适合学习的软件应加入设置中的排除列表。普通输入暂停后可能成为学习候选，不代表助手能判断是否已发送。

网站连接只学习前台聚焦非隐私窗口中的顶层 HTTPS 导航，保留站点首页与时间，不保存路径、查询、片段或网页正文。不扫描浏览历史，也不会把页面上传给 AI；切换已加载标签可能不补记。不同独立日期的使用参与网站推荐，点击后才打开首页。

扩展申请 `webNavigation`、`nativeMessaging`、`storage`、`tabs` 及 HTTPS 页面的内容脚本范围，用于导航、状态及快速词输入；当前不是按站点逐个授权的扩展。只安装时才写本机连接注册表项。固定 manifest `key` 是公开扩展标识用的公钥，不是 API 密钥。

扩展与原生程序交换有界消息，通过当前用户 AppData 下的有限本地队列转交运行中的助手。主程序复核暂停、开关、敏感场景和事件时效。没有 HTTP 监听端口；本机连接不是隔离同用户恶意程序的安全沙箱。

## 移动、卸载与排查

移动运行目录后重新执行 Install-Bridge.cmd，并更新浏览器加载目录；若开启开机启动，关闭后重新开启以更新路径。

卸载时关闭相应开关、运行 Uninstall-Bridge.cmd，再从浏览器移除扩展。脚本移除自己的本机连接注册值及 native-host.json，不删除已学数据；词句与记忆可在 Satori 中另行清除。

未连接时检查安装脚本是否报错、目录是否移动、真实助手是否运行、是否暂停以及功能是否开启。网页预览和 demo 不接收真实浏览器事件。请勿把生成的 native-host.json、浏览器队列或真实词库提交 GitHub。
